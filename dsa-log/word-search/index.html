    Given an m x n grid of characters board and a string word, return true if word exists in the grid.

    The word can be constructed from letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same letter cell may not be used more than once.

    Example 1:

    Input: board = `[[“A”,“B”,“C”,“E”],[“S”,“F”,“C”,“S”],[“A”,“D”,“E”,“E”]], word = “ABCCED” Output: true

    Example 2:

    Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = “SEE” Output: true

    Example 3:

    Input: board =` [[“A”,“B”,“C”,“E”],[“S”,“F”,“C”,“S”],[“A”,“D”,“E”,“E”]], word = “ABCB” Output: false

    3. “Consuming” a Path (Perfect!)

    You said: we can "sink" the word and then continue our recursive calls and then once done we can "unsink" it ie remark it?

    This is exactly what backtracking is. It is the perfect “Choose, Explore, Undo” pattern.

    • “Sink” (Choose): Before you make the recursive calls for the neighbors, you need to change board[row][col] to a special character (like # or None) to mark it as “currently in use on this path.”
    • “Explore”: Make your four recursive calls.
    • “Unsink” (Undo): After the recursive calls are all done (regardless of whether they succeeded or failed), you must restore the board: board[row][col] = original_char. This is the crucial cleanup step that allows other search paths to use this character.

def dfs_word_search(row, col, index, word, board):
	# failed base case 1 for boundary cases 
	if row < 0 or row >= len(board) or col < 0 or col > len(board[0]): 
		return False
	# failed base case 2 for character mismatch
	if board[row][col] != word[index]:
		return False
	# pass base case for finding all the characters
	if index == len(word)-1:
		return True
	
	# choose 
	original_char = board[row][col]
	board[row][col] = '#' # sink character
	
	# Explore
	left = dfs_word_search(row-1, col, index+1, word, board)
	right = dfs_word_search(row+1, col, index+1, word, board)
	top = dfs_word_search(row, col-1, index+1, word, board)
	bottom = dfs_word_search(row, col+1, index+1, word, board)
	
	# undo
	board[row][col] = original_char
	
	return left or right or top or bottom

    This is a common logical step that’s easy to miss.

    Right now, your code says: “Find the first character. If you find it, start a search. Whatever that search returns (True or False), immediately stop and return that result.”

    What you want it to say is: “Find the first character. If you find it, start a search. If that search is successful (returns True), then we are done and can return True. If it’s not successful, then just keep looking for other possible starting characters in the grid.”

    The fix is very simple. You just need to wrap your call to the DFS helper in its own if statement.

    Let’s trace this corrected logic with our word = "ASAD" example.

    1. Loop finds ‘A’ at (0,0).
    2. if dfs(0,0,0, ...) is called.
    3. Let’s assume this path fails, so the dfs call returns False.
    4. The inner if False == True: condition is not met.
    5. The for loops continue. They don’t stop.
    6. Eventually, the loops get to i=1, j=0. board[1][0] is ‘A’.
    7. if dfs(1,0,0, ...) is called.
    8. Let’s assume this path succeeds ((1,0) -> (0,1) -> (0,0) -> (1,1) is not a valid path, but assume (1,0)->(0,0)->(0,1)->... finds the word). The dfs call returns True.
    9. The inner if True == True: condition is met.
    10. The main function return True and everything stops.

    This structure ensures you only exit the function early on a success, allowing the search to continue from all possible starting points if the initial ones are dead ends.
